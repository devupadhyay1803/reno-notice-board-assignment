# Amity Notice Board

A Notice Board application built with Next.js, Prisma, and TiDB for the Reno Platforms Web Development Internship Assignment.

## Features

- Create, edit, and delete notices
- Search notices
- Category filtering
- Notice detail pages
- Dark mode toggle
- Responsive UI
- TiDB database integration using Prisma ORM

## Tech Stack

- Next.js 14
- React 18
- Prisma ORM
- TiDB Cloud
- Vercel
